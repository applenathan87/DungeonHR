## 개요 (Overview)

「마왕성 인사팀」은 판단 게임이다. 뼈대는 케이스(지원자) 데이터를 읽고, 그날 지침에 비추어 깃펜으로 근거를 긋고, 도장으로 판정하는 되풀이이며, 그 위에 면접(카드·코스트), 도구, 승진·경제, 하루와 레벨이 얹힌다. 추가 업무(면접 시간표 퍼즐, 리듬·QTE 미니게임)와 밤 파트(지도 화면·인물·관계→카드)가 "읽기만 하는 게임"을 막는다. 모든 시스템은 필라 우선순위(마왕성의 상식 → 우리 회사 → 물건 → 승진)를 따르고, 어떤 도구도 합격·불합격 정답을 직접 알려 주지 않는다.

시스템으로 두지 않은 것: 화면 요소(UI·HUD)·자막·종이 글씨 그림틀은 화면 설계 문서(`/ux-design`)로, 오디오는 각 GDD의 Visual/Audio 부분과 사운드 기준 문서로, 케이스 콘텐츠(지원자·대사) 자체는 M02 끝-M05의 기획 작업에서 기능과 같이 쓴다(M02 끝-M03 사원 단계 서류 · M04 대리 Lv1과 Lv2 시작 · M05 대리 Lv2·Lv3 — 레벨마다 최소 이틀치, 합 36-48건).

### 시스템별 범위 (각 GDD가 담을 것)

1. **케이스 데이터와 콘텐츠 제작 흐름** — 지원자·JD·지침·카드·대사·해설·사건 문구를 파일에 적는 양식. JSON에서 시트로 넘어가는 시점(케이스 20건 이상). 불러올 때 잘못 쓴 곳을 찾는 검사(결정적 단서가 있는지, 줄 수 한계 등). 레벨별 후보 목록 표시(데모는 레벨마다 최소 이틀치), 겹치지 않게 섞어 뽑기(고정 건은 튜토리얼용만), 뽑은 순서 저장(케이스와 지침에 공통 적용). 건마다 난이도 표시(쉬움·보통·어려움 — 그날의 지원자를 더미별 비율로 뽑는다), 아침 보고서 문구(잘못 통과·잘못 탈락), "재지원" 표시(2026-10-04, [day-and-level.md](day-and-level.md) 3-5·3-7). 글(스트링)은 전부 스트링 테이블에 두고 스트링 키로 불러 쓰며 언어별 표를 둔다(데모는 한국어만 — 2026-09-30 영문 제외. 스트링 테이블을 쓰는 것은 2026-10-01에 확정했고, 스트링 키를 붙이는 규칙은 이 GDD에서 정한다). 지원자마다 지원 직무 하나와 기본 정답(사람이 적음), 인적 사항(당일 지침과 채용 규정이 보는 사실 — 이력서에 적힌 것과 기믹으로 드러나는 것)을 적는다. 같은 종족이 다른 직무에 지원하면 다른 지원자로 쓴다 — 기본 모델은 같이 쓰고 액세서리·색·이름을 바꾼다(2026-10-07, [daily-guidelines.md](daily-guidelines.md) 3-2·3-3).
2. **당일 지침** — 그날의 공문(당일 지침 한 장 — 사정 한 줄 공문 말투 + 지침 한 줄 외침. 직무 요건서는 서랍에)과 정답 규칙. **정답은 세 겹**(당일 지침 → 채용 규정 → 직무 적합), 위가 이긴다. 지침은 그날 하루만 통하고 합격 쪽으로도 불합격 쪽으로도 뒤집으며, 인적 사항(이력서에 적힌 사실·기믹으로 드러난 사실)으로 걸린다(2026-10-07). 지침 후보 목록은 레벨마다 있고, 새 레벨의 첫날은 정해 둔 지침(사원 Lv2 바로 불합격 → Lv3 규정 끄기 → 대리 Lv1 바로 합격 → Lv2 없음 → Lv3 규정 뒤집기 = 사기 부서의 날), 머무는 날은 그 레벨 후보에서 랜덤(없는 날도 있고 어제 지침은 뺀다). 지침이 있는 날은 정답이 뒤집히는 지원자가 한 명은 나온다. 이력서 칸도 레벨에 묶인다(희망 연봉 = 사원 Lv3부터)(2026-10-08). 공문은 서랍이 아니라 책상 위에 보인다 — 출근하면 바로 읽히고 한켠에 놓인다(2026-10-01). 옛 열린 질문 #11(공문이 날마다 바뀌는 방식)은 여기서 풀렸다. **룰북은 [daily-guidelines.md](daily-guidelines.md)에 다 썼다 (2026-10-08)**.
3. **판정(근거 긋기·도장·도구)** — 이력서·공문 대조, 깃펜으로 V나 X 긋기(어느 쪽 근거인지), 근거 최소 1개, 도장으로 합격·불합격, 3단 채점(맞힘 / 반전을 잘못 읽음 / 결정적 단서를 놓침). 정답은 당일 지침 GDD의 정답 규칙이 정하고, 판정은 그 기준으로 채점만 한다(2026-10-01). 서류 기믹(사원 Lv2·Lv3 자리 — 후보 촛불)과 도구의 "정보만 준다" 규칙, 사용 제한, 승진 보상과의 연결. 열린 질문: 보류 도장, 능력치 창, 끌어서 다시 놓기, 근거 긋기의 조절값. 채용 규정(레벨이 오르며 늘어나고 계속 통하는 규칙 — 예: 촛불로 위조가 드러난 서류는 불합격)도 판정이 맡는다(2026-10-07). 근거를 긋는 자리 = 이력서 본문 줄 + 머리 칸(이름·종족·출신 같은 칸) + 사진 칸 — 사진이 없거나 다른 이력서는 사진 칸에 X를 그어 탈락 근거로 삼는다("사진이 다르다"가 무엇과 다른 것인지는 여기서 정한다). 당일 지침에서 건마다 정답·결정적 단서 자리·맞는 방향·정답이 나온 겹을 받는다. 사기 부서의 날을 위해 대리 Lv2에 "면접 진술에서 거짓말이 드러나면 불합격" 채용 규정을 두자는 제안이 있다(면접 GDD와 함께 확정) (사용자, 2026-10-07, [daily-guidelines.md](daily-guidelines.md) 3-5·3-6).
4. **조작** — 잡기·끌기·던지기·놓기·들어서 읽기의 공통 규칙. 이력서와 공문은 따로 집는다 — 이력서를 집으면 이력서만 들리고, 같이 보려면 공문도 집는다(2026-10-01, 옛 "함께 들기"를 바꿈). 만지는 물건은 6종까지. 도장·카드 손맛(손맛을 다루는 Game Feel 부분이 핵심: 입력 지연, 타격감, 무게감). 소리·잉크·짧은 움직임 애니메이션으로 주는 반응. 컨셉에서 확인하기로 한 점 "도장이 계속 찍고 싶은가". **범위** (2026-10-07, 옛 이름 책상 위 물건 다루기): 낮에 책상 위 물건을 다루는 공통 조작과 그 손맛까지. 미니게임의 버튼 입력과 밤 지도 화면의 클릭은 각자의 시스템이 맡는다. 근거 긋기와 도장은 긋고 찍는 손동작과 느낌만 여기서, "어느 줄이 근거인지·합격인지"라는 뜻은 판정이 맡는다. 서류를 속이는 것은 "조작"이 아니라 늘 "위조"라고 쓴다.
5. **하루와 레벨** (옛 하루 구조·결산) — 하루의 순서(출근 → 아침 사건 보고서 → 공문 → 업무 → 추가 업무(사원 단계까지는 시키고 대리부터는 자발적 야근, 근무 시간 밖) → 퇴근 결산 → 밤 → 휴식하기·취침)와 **레벨 표**(사원 Lv1-3 서류 → 대리 Lv1-3 면접, 레벨에 묶인 것은 그 레벨에 처음 올라간 날 나온다). 근무 시간(케이스마다의 타이머는 없음)과 전부 처리 시 추가 점수. 승진 심사가 열리는 조건(공적이 차야만 오른다. 직급이 바뀌는 승진 = 공적 + 밤에 건네는 상납 봉투 — 2026-10-04), 같은 레벨에 머무는 날, 준비한 후보가 바닥나는 날(재지원). 재도전 없음 — 항상 다음 날로(해고만 예외). 게임오버(경고장이 쌓이면 해고 → 최근 저장 불러오기 또는 타이틀로 — 데모에도 있다). 결산 3단 채점 공개 범위, 다음 날 사고(아침 사건 보고서), 휴식하기 자동 저장과 이어 하기, 엔딩(대리 Lv3에서 공적이 차고 그날 밤 상납 봉투를 건네면 — 등급 대신 인사 평가서), 요일(보여 주기만). **룰북은 [day-and-level.md](day-and-level.md)에 다 썼다 (2026-10-04)**.
6. **승진·경제** — 공적 공식(정확 ×2 + 근거 적중 ×1 + 처리량 보너스), 직급 사다리(데모 = 사원·대리, 임시 이름 · 본편 = 수습 → … → 팀장), 승진 보상(업무 교체, 도구·카드·장소 해금 — 새 카드를 얻는 세 길 중 하나), 일급(기본급 + 보너스 − 청구서), 골드를 쓰는 곳. 상납 봉투(뇌물 주기)·청탁 골드(뇌물 받기)·꾸미기 물건(능력 없음)은 데모에 넣는다(2026-10-04, [game-flow.md](game-flow.md) B21·B22). 오래 두고 쓰는 소비처는 본편.
7. **1차 면접(카드·코스트)** — 몬스터 등장·반응 2종, 손패 4종과 턴당 코스트(데모 포인트 3), 답변 자막·반응 연출 지시, 진술 줄(근거를 긋는 스텝의 템포를 다시 본다 — B15), 결정적 단서를 카드와 서류에 나눠 두는 규칙, 함정 질문 비용, 면접 기믹(대리 Lv2·Lv3 자리 — 후보 돋보기, 사기 부서의 날), 새 카드가 무엇인가(상점·승진 보상·밤의 세 길 — B20). 덱빌딩은 #11.
8. **면접 시간표 퍼즐** — 사진 카드·수정구 통화·달력 6칸, 세 가지 제약(사진 힌트·통화·칸 경고), 규칙을 어긴 배치도 허용 → 그날 결산에서 벌금, 다음 날 아침 보고서에 이야기(2026-10-04). 프로토타입 구현 있음.
9. **밤 파트** — 지도 화면(장소·인물 아이콘을 눌러 이동, 3D 없음), 일급 정산 화면, 까마귀 상점, 인물 이벤트(호감을 쌓아 두었다가 꺼내 쓰는 방식, 관계 단계 3에서 5), 관계 → 카드(다른 것으로 대신할 수 없는 효과를 가진 카드 몇 장), 인물이 나오는 순서(운이 아니라 정해진 순서, 하루 1에서 2명). 데모 = 일급·상점·인물 1명·카드 1장, 인사권자에게 상납 봉투 건네기와 청탁 받기(2026-10-04). 바·서브스토리·청탁 갈래·석간 신문은 뒤 단계. 근거 = [potionomics-night-rapport.md](../research/ref-games/potionomics-night-rapport.md).
10. **리듬·QTE 미니게임** — 추가 업무로 하는 미니게임 1에서 2종, 입력 타이밍과 판정 허용 시간, 보상(골드·공적 보너스). 형태 미정 — GDD 전에 작은 프로토타입을 만들어 본다. (QTE = 화면 신호에 맞춰 누르는 짧은 조작)
11. **덱빌딩 확장** — 화법·기술 카드, 상점 매매, 뽑기·손패, 게이지·붕괴, 효과의 상한 규칙(카드가 정답을 알려 주면 안 됨). 원문 = [interview_idea.md](../concept/interview_idea.md) v0.3.
12. **저장·설정** — 데모는 휴식하기를 누를 때 자동 저장 하나와 시작 화면의 "이어 하기"(게임오버 뒤 "최근 저장 불러오기"도 같은 저장)만 있고, 이것은 5번 하루와 레벨이 맡는다(2026-10-02 — 옛 "데모는 15분 완주라 저장 없음"을 바꿈). 저장 슬롯과 설정 화면은 데모 뒤. 영문을 빼서 언어 설정도 데모에서 빠진다.

- **쓰는 방식** (2026-10-02): GDD 여덟 칸을 둘로 나눠 두 번에 쓴다. **룰북** = 개요 · 플레이어가 느낄 것 · 상세 규칙 · 다른 시스템과의 관계 — 먼저 쓴다. **밸런스** = 공식 · 예외 상황 · 조절값 · 통과 기준 — 검토(`/design-review`)와 함께 그 부분의 코드를 짜기 직전에 채운다. 해 보기 전에 적은 숫자는 대부분 다시 쓰게 되기 때문이다. 룰북만 쓴 GDD는 밸런스 칸에 "코드 직전에 채움"이라고 적어 둔다. 1번 개요는 다섯 줄로 쓴다([design/CLAUDE.md](../CLAUDE.md)).
- 케이스 데이터가 맨 뒤인 이유: 양식의 칸은 1-6번의 규칙에서 나온다. 사원 단계 케이스를 M02에서 쓰기 시작하므로 양식은 M02 가운데에 정한다.
- 옛 순서 (2026-09-12) = 케이스 데이터 → 지침 → 판정(M01) → 책상 위 물건 다루기 → 하루 구조(M02) → 승진·경제 → 면접(M03) → 퍼즐·밤·미니게임(M04). 그건 코드가 서로 기대는 순서였지 정하는 순서가 아니었다.
- 기획과 제작을 번갈아 한다(2026-09-30): GDD는 곧 만들 부분만 쓴다. 8에서 10번은 프로토타입이 이미 있거나(면접 시간표 퍼즐) 작은 프로토타입을 먼저 만들어 봐야 쓸 수 있다(미니게임, 밤 파트 지도 화면). 마일스톤 정본 = [production/milestones/README.md](../../production/milestones/README.md), 날 수 어림 = 출근부 「마일스톤 판」.
- 작업 방식: 질문은 글로(버튼 UI 금지), 전문 에이전트는 공식·예외 상황·통과 기준처럼 값이 필요한 부분에만. 검토는 새 세션에서 `--depth lean`.

## 서로 물린 의존 (Circular Dependencies)

- **케이스 데이터 ↔ 당일 지침**: 케이스를 적는 양식이 정답 규칙(같은 케이스라도 그날 지침에 따라 정답이 달라지는 방식)을 알아야 한다 → 당일 지침 GDD(M01)에서 정답 규칙을 먼저 정하고, 양식은 M02에서 확정한다.
- **판정 ↔ 면접**: 진술에 근거를 긋는 방식은 판정의 것이고, 면접은 진술을 대 준다 → 근거 긋기와 정답 규칙은 판정이 맡고, 면접은 진술을 이력서 줄과 같은 데이터로 넘긴다.
- **승진·경제 ↔ 밤 파트**: 골드 수입은 경제, 쓰는 곳은 밤 → 공식과 잔액은 경제가 맡고, 밤 파트는 거래 목록(가격·효과)만 가진다.
