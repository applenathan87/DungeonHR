## 고르는 방법 (2026-10-03, 사용자)

- **강의는 미리 순서를 정하지 않고, 할 일 목록에도 넣지 않는다.** 강의 하나를 처음부터 끝까지 듣기보다 스타일라이즈드 모델링·스컬핑 강의를 여러 개 들으며 작업을 쌓는다. 필요한 기능은 그때그때 찾아 배운다. 듣다가 맞지 않으면 바로 바꾼다.
- 강의를 들은 날 출근부에 "블렌더 강의"처럼 직접 적고, 배운 것을 메모에 짧게 남긴다.
- 할 일로 두는 것은 결과물이 남는 실습뿐이다(던전 문, 도장, 고블린). 마일스톤 판에는 시간 몫으로 「아트 공부」 카드가 있다.
- 언제까지 익혀 둘 것: 텍스처 칠하기 = 11/11 도장 확인 전 · 캐릭터 스컬핑 = M02 고블린 전.
- 지난 계획(블렌더 복습 → 던전 문 → 페인터 기초 → 텍스처 → 캐릭터 스컬핑 순서)은 git 기록에 있다.
