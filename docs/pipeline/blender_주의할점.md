# 블렌더 주의할 점 — 모델링에서 스컬핑으로 넘어가기 전에

> 2026-10-07, 로고 바탕(그때 `LOGO_BASE_test.blend`, 지금 [artwork/logo/logo_model.blend](../../artwork/logo/))을 스컬핑하기 전에 Claude가 점검하면서 나온 실수와 확인할 것을 모았다. 블렌더 5.2 기준. 오브젝트 이름은 같은 날 정리한 뒤의 이름으로 적었다.
> 메뉴 이름은 영어로 적고 한글을 괄호에 붙였다. 한글판 메뉴 이름은 조금 다를 수 있다.
> 같이 보는 문서: [sculpting_brush.md](sculpting_brush.md)(브러시 강의) · [blender-to-unity.md](blender-to-unity.md)(유니티로 보내기)

## 한눈에 — 스컬핑 시작 전 체크

1. 다른 이름으로 저장해서 복사본을 만들었다
2. 모든 조각의 크기·회전을 적용했다 (오브젝트 속성의 Scale이 1, 1, 1)
3. 면 방향 오버레이에 빨간 면이 없다
4. 구멍, 안에 숨은 면, 겹친 점, 떨어진 점이 없다
5. 스컬핑할 조각의 불리언을 적용했다
6. 원점이 각 조각의 몸 가까이에 있다
7. 리메쉬 크기를 조각 두께에 맞게 정했다

## 자주 한 실수

### 크기(스케일)를 적용하지 않음

**어떻게 생기나.** 오브젝트 모드에서 S로 늘리거나 줄이면 모양 자체는 그대로 두고, 오브젝트에 "몇 배로 보여 줘"라는 값만 붙는다. 평면을 그린 뒤 R X 90으로 세우면 회전값도 같은 식으로 붙는다.

**왜 문제인가.** 고무판을 한쪽으로만 잡아 늘려 놓고 그 위에 도장을 찍는 것과 같다. 블렌더는 늘리기 전 모양에 조각한 뒤 늘려서 보여 주기 때문에 동그란 브러시가 타원으로 찍히고, 방향마다 세기도 달라진다. 리메쉬 크기와 다인토포(Dyntopo) 디테일도 늘리기 전 크기를 기준으로 계산돼서 촘촘한 정도가 방향마다 달라진다. 유니티로 보낼 때도 문제가 된다.

**고치는 법.** 메쉬를 전부 선택하고 Ctrl+A → Rotation & Scale(회전 및 스케일).

**습관.** 모양을 잡은 뒤 다음 단계로 넘어가기 전에 Ctrl+A를 한 번 한다. 오브젝트 속성(N 패널)의 Scale이 1, 1, 1이 아니면 아직 적용하지 않은 것이다.

**이번 로고에서.** 메쉬 58개 중 43개. 가장 심한 것은 PIPE_center(18배 차이), pillar_L(11배), Flag_center(8배), HORN_L(7배)였다.

### 마이너스 크기로 뒤집기

**어떻게 생기나.** 왼쪽 조각을 복사해서 오른쪽에 쓰려고 S → X → -1 처럼 크기를 음수로 만들어 거울처럼 뒤집을 때 생긴다.

**왜 문제인가.** 블렌더 화면에서는 멀쩡해 보이지만 속으로는 안팎이 뒤집힌 상태다. 크기를 적용할 때나 다른 프로그램(유니티, 페인터)으로 보낼 때, 면이 안쪽을 보는 문제가 되기 쉽다.

**고치는 법.** 크기를 적용한 뒤 뷰포트 오버레이 → Face Orientation(면 방향)을 켠다. 파랑이 바깥, 빨강이 안쪽이다. 빨간 면이 있으면 편집 모드에서 A → Shift+N(바깥쪽으로 다시 계산).

**습관.** 좌우로 뒤집을 때는 미러 모디파이어(Mirror)를 쓰거나, 편집 모드에서 뒤집은 뒤 바로 면 방향을 확인한다.

**이번 로고에서.** upper_pillar_L, METAL_L·R, Lower_METAL_L·R.

### 돌출(E)을 우클릭으로 취소

**어떻게 생기나.** E를 누른 뒤 마음이 바뀌어 우클릭이나 Esc를 누르면 "움직인 것"만 취소된다. 복사된 면은 처음 자리에 그대로 남는다. 같은 자리에 점과 면이 두 겹으로 겹친 상태라 눈으로는 보이지 않는다.

**왜 문제인가.** 스컬핑하면 그 자리가 찢어지거나 뾰족하게 튄다. 베벨이나 서브디비전도 이상하게 나온다.

**고치는 법.** 편집 모드 → A → M → By Distance(거리로 병합). 합쳐진 점 개수가 화면 아래에 뜬다.

**습관.** E를 취소하고 싶으면 우클릭 대신 **Ctrl+Z**.

**이번 로고에서.** pillar_L(점 4개), PIPE_center(점 10개, 오른쪽 끝).

### 안에 숨은 면, 구멍

**어떻게 생기나.**
- 반쪽을 만들고 미러로 합칠 때, 가운데 잘린 자리의 면을 지우지 않으면 몸 안에 칸막이로 남는다.
- F로 면을 채우다가 엉뚱한 점들을 이어 붙이면 몸 한가운데에 막이 생긴다.
- 면을 지우거나 이어 붙이다가 한쪽이 비면 구멍이 남는다.

**왜 문제인가.** 스컬핑용으로 점을 늘리는 복셀 리메쉬는 "물이 새지 않는 통"을 전제로 속을 채운 뒤 겉면을 새로 만든다. 구멍이 있으면 물이 새고, 칸막이가 있으면 그 자리가 뭉개진다.

**찾는 법.** 편집 모드에서 Select(선택) → Select All by Trait(특성으로 모두 선택) 아래에서 고른다.
- Non Manifold(비다양체): 구멍 테두리, 면 3장 이상이 붙은 모서리
- Interior Faces(내부 면): 몸 안에 숨은 면

**고치는 법.** 숨은 면은 지운다(X → Faces). 구멍은 테두리를 골라 F나 Alt+F로 막는다.

**이번 로고에서.**
- BASESTONE: 판 정중앙(x=0)에 칸막이 면 5장
- Flag_L·R: 뒷면이 없고, 위쪽 양 모서리에 대각선 면이 하나씩 끼어 있었다
- Flag_center: 두께 한가운데에 8각형 막이 떠서 해골 아랫부분을 가리고 있었다

### 떨어진 점, 면 없는 선 (찌꺼기)

**어떻게 생기나.** 면을 지울 때 점이나 선만 남거나, P로 일부를 떼어 낼 때 점 하나가 남는다.

**왜 문제인가.** 오브젝트 모드 화면에 선이 그대로 그려진다. 이번 로고에서는 아래 판 양 끝 장식이 "×"로 보였는데, 이게 면 없는 선이었다. 리메쉬·내보내기에서도 쓸모없는 찌꺼기가 된다.

**고치는 법.** 편집 모드 → Mesh(메쉬) → Clean Up(정리) → Delete Loose(느슨한 것 삭제).

**이번 로고에서.** SKULL_MAIN 점 1개(눈 구멍 자르개를 떼어 낸 자리), Lower_METAL_L·R 선 4개씩, 글자 WANG_01 선 32개(동그라미 하나가 선으로만 남음).

### 원점이 엉뚱한 곳에 있음

**어떻게 생기나.** 다른 조각을 복사(Shift+D)한 뒤 편집 모드에서 통째로 옮기면, 원점은 복사해 온 자리에 남는다. 몸은 왼쪽에 있는데 손잡이는 오른쪽에 있는 셈이다.

**왜 문제인가.** 회전·크기 조절의 중심이 엉뚱한 곳이 된다. 스컬핑 대칭은 원점을 기준으로 거울을 놓는다. 유니티에서도 피벗이 어긋난다.

**고치는 법.** 오브젝트 모드 → Object(오브젝트) → Set Origin(원점 설정) → Origin to Geometry(지오메트리로 원점).

**습관.** 복사한 뒤에는 오브젝트 모드에서 G로 옮긴다. 편집 모드에서 옮겼다면 바로 원점을 맞춘다.

**이번 로고에서.** lower_pillar_L(upper_stone_R를 복사한 것으로 보임, 원점이 2.2m 떨어진 반대편에 있었다), SKULL_MAIN, Sub_STONE(원점이 바닥 (0,0,0)에 있었다).

### 불리언을 적용하지 않고 스컬핑

**왜 문제인가.** 스컬핑과 리메쉬는 "구멍이 뚫리기 전 원본"에 한다. 불리언이 남아 있으면 구멍 가장자리를 다듬을 수 없고, 붓질할 때마다 구멍을 다시 계산해서 느려진다.

**고치는 법.** 모디파이어 이름 옆 ∨ → Apply(적용). 자르개 오브젝트는 숨겨 둔 채 남겨도 된다(나중에 다시 쓸 때 대비).

**이번 로고에서.** 해골(눈·코 구멍)을 적용했다. 글자의 불리언 6개는 글자를 작업할 때 본다.

## 스컬핑 직전에 확인할 것

### 복사본부터

리메쉬는 되돌리기 어렵다. 다른 이름으로 저장하거나, 로우폴리를 복사해서 숨긴 컬렉션에 보관한다.

### 점을 늘린다

모델링을 막 끝낸 조각은 면이 수십~수백 장이라, 찰흙으로 치면 철사 뼈대만 있는 상태다. 붓질할 점이 없으니 리메쉬로 먼저 촘촘하게 만든다.
- 스컬프트 모드에서 **R** = 리메쉬 크기 정하기, **Ctrl+R** = 리메쉬 실행
- 크기 설정은 Properties(속성) → Object Data(오브젝트 데이터, 초록 삼각형) → Remesh(리메쉬) → Voxel Size(복셀 크기)에도 있다

### 리메쉬 크기 정하는 법

- **상한 = 가장 얇은 부분 두께의 1/4.** 이보다 크면 얇은 부분이 통째로 사라지거나 구멍이 난다. 기본값 0.1m는 이 로고에서는 거의 모든 조각을 망가뜨린다.
- **실제 값 = 얼마나 잘게 조각하고 싶은가.** 상한보다 작게 고른다. 작을수록 면이 많아지고 무거워진다(크기를 절반으로 줄이면 면은 약 4배).
- 한 작품 안에서는 비슷한 크기로 맞추면, 돌결의 굵기가 조각마다 들쭉날쭉하지 않다.

**이번 로고(가로 4.5m)에 넣어 둔 값**

| 조각 | 실제 두께 | 리메쉬 크기 | 예상 면 |
|---|---|---|---|
| 깃발 Flag_L·R | 약 1.2cm | 0.003m | 각 5만 |
| 뿔 HORN_L·R | 4.4~5.9cm | 0.01m | 각 2천 |
| 해골 SKULL_MAIN | 7.7cm | 0.01m | 5천 |
| 바닥 돌판 BASESTONE | 21cm | 0.01m | 13만 |
| 나머지 돌·기둥·파이프·Flag_center | 9~26cm | 0.01m | 합쳐 약 15만 |

처음 점검 때 깃발 두께를 5.6cm라고 했는데, 그건 기울어진 깃발의 앞뒤 폭이었다. 실제 판 두께는 1.2~1.5cm다. 두께는 바운딩 박스 숫자(Dimensions)가 아니라 실제 판의 앞면에서 뒷면까지로 봐야 한다.

### 리메쉬하지 않는 것이 나은 조각

복셀 리메쉬는 날카로운 모서리를 둥글게 만든다. 돌에는 오히려 좋지만 각진 금속 장식(METAL·Lower_METAL·DIA_center·Chain)은 그대로 두는 게 낫다.

### 멀티레졸루션(Multires)을 쓰는 강의라면

멀티레졸루션은 사각형 면 위주여야 깨끗하게 나뉜다. 꼭짓점이 5개 이상인 다각형 면이 있으면 그 자리가 뭉개지니, 리메쉬를 먼저 하는 편이 낫다. 이번 해골은 불리언을 적용한 뒤 앞면이 꼭짓점 56개짜리 면 하나가 됐다.

### 한 번에 한 조각

스컬프트 모드는 선택된 오브젝트 하나에만 조각한다. 조각이 따로따로면 하나씩 바꿔 가며 한다.

### 좌우 대칭

헤더의 대칭(X) 버튼 상태를 확인한다. 거울은 원점을 기준으로 놓인다. 이번 해골은 그림을 따라 그려서 좌우가 평균 2.5cm씩 다르기 때문에, 대칭을 켜면 반대쪽 붓질이 어긋난다. 원점이 정중앙이고 좌우가 같은 조각에만 켠다.
